# Zomato-Data-Analytics-Internship
Data Analytics Internship Project using Python, Power BI and Machine Learning.
# Task 1 – Zomato Restaurant Analytics Dashboard

## Overview
This task focuses on analysing Zomato restaurant data using Microsoft Power BI. An interactive dashboard was developed to present restaurant-related insights through visualisations and key performance indicators.

## Tool Used
- Microsoft Power BI

## Dataset
The Zomato restaurant dataset contains information about restaurant names, locations, cuisines, ratings, votes, pricing and service availability.

## Dashboard Features
- Total number of restaurants
- Restaurant distribution by country and city
- Cuisine analysis
- Restaurant rating analysis
- Average cost for two
- Restaurant and locality insights

## Objective
To transform restaurant data into meaningful visual insights and make the information easier to understand through an interactive dashboard.

## Output
The Power BI dashboard and its screenshot are included in this folder.
