# Task 4 – Data Cleaning and Reporting Automation

## Overview
This task focuses on cleaning and preprocessing the Zomato restaurant dataset using Python. A Python script was developed to automate data cleaning operations and generate reports and visualisations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning Operations
- Loading the Zomato dataset
- Identifying missing values
- Checking and removing duplicate records
- Handling missing values
- Converting numerical columns into appropriate data types
- Standardising text values
- Handling invalid data values

## Generated Outputs
- `zomato_cleaned.csv` – Cleaned dataset
- `rating_distribution.png` – Restaurant rating distribution chart
- `top_cities.png` – Chart showing the top cities
- `cleaning_report.txt` – Automated data cleaning report

## Execution
The Python script reads the original Zomato CSV dataset, performs the cleaning operations and saves the generated files in the outputs folder.
